# 게임 개발 포트폴리오

게임을 만드는 기반 기술부터 실제 플레이까지, 세 가지 관점의 개발 경험을 담았습니다.

| 프로젝트 | 살펴볼 개발 경험 | 링크 |
| --- | --- | --- |
| **Flaw Engine** | C++ 기반 엔진 구조와 게임 제작 도구 개발 | [저장소](https://github.com/rurain7763/Flaw) |
| **PingPong** | Unity 클라이언트와 C++ 서버를 연결한 PVP 게임 개발 | [클라이언트](https://github.com/rurain7763/PingPong) · [서버](https://github.com/rurain7763/PingPongServer) · [시연 영상](https://youtu.be/oiZ5a--pyvM) |
| **RPG** | Unity 기반 2D 액션 게임의 전투와 콘텐츠 시스템 개발 | [저장소](https://github.com/rurain7763/RPG) |

각 프로젝트의 구현 내용, 코드 구조와 실행 방법은 연결된 저장소에서 확인할 수 있습니다.
